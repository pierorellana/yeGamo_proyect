# Metricas y analitica de producto

## North Star
Viajes completados dentro de la ventana prevista.

## Funnel
Search -> Plan success -> Option selected -> Journey started -> Journey completed -> On-time.

## Calidad de ETA
- MAE en minutos.
- % dentro de +/-5, +/-10 min.
- error por ruta/franja/proveedor.
- calibration de arrival window.

## Producto
- DAU/WAU/MAU.
- retencion D1/D7/D30.
- perfiles recurrentes activos.
- alertas de salida abiertas/accionadas.
- frecuencia de replanificacion.

## Integraciones
- latencia p50/p95 por proveedor.
- tasa de error.
- fallback rate.
- cache hit permitido.
- costo por 1.000 planes.
- cobertura geografica efectiva.

## Confianza
- discrepancias reportadas.
- % de rutas con muestra suficiente para score.
- estabilidad del yeGamo Score.

# Referencias de investigacion

- **SRC-01 - ATM - Movilidad.** La ATM describe el sistema de movilidad de Guayaquil y afirma que para buses urbanos se pueden consultar rutas, recorridos, buses disponibles e informacion en tiempo real.
  https://atm.gob.ec/movilidad/
- **SRC-02 - ATM - Observatorio de Movilidad.** Portal de datos abiertos de movilidad y seguridad vial. Actualmente el contenido visible se concentra en siniestralidad y estadisticas, no en una API publica de rutas/vehiculos.
  https://atm.gob.ec/observatorio/
- **SRC-03 - Municipio de Guayaquil - Plan Maestro de Transporte Publico Inteligente.** En marzo de 2026 el Municipio anuncio un estudio para un sistema inteligente de transporte publico, reestructuracion de rutas, operacion inteligente y centro de control, con resultados previstos para finales de 2026.
  https://guayaquil.gob.ec/kotra-inicia-nuevos-estudios-ciudad-parte-convenio-municipio-guayaquil/
- **SRC-04 - Google Routes API - Transit.** Permite solicitar rutas de transporte publico y obtener detalles de paradas, tiempos de llegada/salida, linea, headsign, polilineas y tramos a pie, sujetos a cobertura, facturacion y terminos de Google Maps Platform.
  https://developers.google.com/maps/documentation/routes/transit-route
- **SRC-05 - Transitland v2 REST API.** Catalogo/API de feeds y entidades GTFS con plan gratuito de baja cuota y API key. Puede exponer feeds, rutas, paradas, viajes y descargas GTFS/GTFS-RT cuando existan y su licencia permita redistribucion.
  https://www.transit.land/documentation/rest-api
- **SRC-06 - Mobility Database API.** Catalogo global de feeds GTFS/GTFS-Realtime. La API usa OAuth2 y permite descubrir feeds y datasets.
  https://mobilitydata.github.io/mobility-feed-api/SwaggerUI/index.html
- **SRC-07 - OpenStreetMap Overpass API.** API de solo lectura para consultar elementos de OpenStreetMap, incluidas paradas y relaciones de transporte publico cuando estan mapeadas.
  https://wiki.openstreetmap.org/wiki/Overpass_API
- **SRC-08 - Nominatim Usage Policy.** El servicio publico de geocodificacion exige uso moderado, maximo 1 solicitud/segundo, atribucion y no admite autocomplete; para produccion a escala se recomienda proveedor propio o tercero.
  https://operations.osmfoundation.org/policies/nominatim/
- **SRC-09 - Moovit Public Transit APIs.** Moovit documenta APIs de transporte publico, pero requieren API key, licencia/secret HMAC y, para ciertos usos, relacion comercial y metro ID.
  https://api-docs.moovit.com/
- **SRC-10 - Moovit - Guayaquil.** Moovit publica planificacion, rutas y tiempos de buses para Guayaquil, lo que confirma disponibilidad de datos en su plataforma de consumo, no necesariamente acceso abierto a esos datos.
  https://moovitapp.com/bus/guayaquil/es-419
- **SRC-11 - Waze for Cities - Data Feed.** Los socios Waze for Cities pueden recuperar trafico, alertas e irregularidades mediante un feed GeoRSS JSON/XML. Requiere ser socio y un acuerdo de comparticion.
  https://support.google.com/waze/partners/answer/13458165?hl=es
- **SRC-12 - GTFS - Descripcion general.** GTFS define formatos abiertos para datos estaticos (rutas, paradas, horarios) y tiempo real (posiciones, actualizaciones de viaje, alertas).
  https://gtfs.org/es/documentation/overview/

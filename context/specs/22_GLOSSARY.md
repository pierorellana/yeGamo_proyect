# Glosario

- **ETA:** Estimated Time of Arrival.
- **GTFS Schedule:** formato abierto para agencias, rutas, paradas, viajes y horarios.
- **GTFS-Realtime:** extension para trip updates, vehicle positions y service alerts.
- **HeadSign:** texto/direccion mostrada por una linea o viaje.
- **Leg:** tramo individual de un itinerario (caminata o transporte).
- **Journey Plan:** conjunto de alternativas para un origen/destino.
- **Arrival window:** rango en el que se espera llegar.
- **Indice de fiabilidad yeGamo:** indicador interno 0-100 de estabilidad/confiabilidad basada en evidencia.
- **Live vehicle:** posicion reportada por fuente autorizada con timestamp reciente.
- **Estimated vehicle:** posicion inferida; nunca equivalente a GPS real.
- **Provider:** servicio externo de transit/geocoding/traffic.
- **PostGIS:** extension geoespacial de PostgreSQL.

- **Data State:** estado normalizado de calidad/frescura: CURRENT, STALE, DEGRADED, OFFLINE_CACHE o UNAVAILABLE.
- **Prototype mock:** dato usado solo para representar la experiencia; no implica que exista una fuente productiva.

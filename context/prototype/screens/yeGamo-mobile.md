# Baseline de pantallas móviles yeGamo

Esta tabla es una matriz de trazabilidad de la baseline. Tiene exactamente 17
filas de pantalla; los nueve valores de `states` son estados UX reutilizables,
no pantallas adicionales. Las rutas son las operaciones canónicas del API
versionado bajo `/v1`. `—` significa que la pantalla no necesita una llamada
remota para renderizar su estado inicial.

## Estados compartidos

Los estados de la columna `states` son presentacionales y se mapean desde
`dataState`/errores del API. En todos los módulos deben existir acciones de
recuperación apropiadas (`reintentar`, cambiar hora, usar origen manual,
permitir más caminata o volver). Un estado `offline` puede mostrar cache solo
como `OFFLINE_CACHE`/`STALE` con frescura visible; nunca como ETA actual.
